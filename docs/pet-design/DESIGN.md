## 1. 设计原则

1. **人设优先**：用户一眼认出「大师姐」——Q 版立绘、播放键 ▶、耳麦、星星发卡元素贯穿 UI；
2. **宠物感**：窗口小巧、圆角、置顶、可拖、可收起；有呼吸动画和气泡对话；
3. **报告进展**：保持现有 8 阶段勾选表信息量，但视觉简化为时间线 + 环形总进度；
4. **配置极简**：常用（录像地址）一步可达，低频（租户 ID）收在设置区；
5. **工程可达**：tkinter 可实现（不引入 Electron 级重依赖），素材为透明 PNG。

- 阴影：`0 8~18px rgba(58,50,56,.2~.35)`（窗口悬浮感）。

## 3. 布局与形态

### 3.1 展开态（默认，342×~640）

```
┌──────────────────────────────┐
│ ◉大师姐   [租户·dashijie] — ✕ │ ← 标题栏（拖动区）+ 租户徽章
├──────────────────────────────┤
│   (气泡)      ⟳4/8           │ ← 宠物区 168px
│      🧍Q版立绘（浮动）          │    跑链时右上角转圈
├──────────────────────────────┤
│ ⭐击倒14 🎒拾取9 🎙语音6       │ ← 战绩条（最近/刚完成场次）
├──────────────────────────────┤
│ ✓下载 86s    ✓转写 540s       │ ← 阶段时间线
│ ✓说话人 95s  ▶OCR检测…        │
│ ○击倒切片   ○拾取切片         │
│ ○语音评估   ○推评估包          │
├──────────────────────────────┤
│ 🎬 录像地址  [BV…/URL/目录 ▾]📁│ ← 配置卡
│ 🏷 租户ID    [dashijie    ]💾 │
│ [●] 推评估并打标 --run-eval   │
├──────────────────────────────┤
│ [   ▶ 开始跑链   ]            │ ← 珊瑚粉渐变主按钮
└──────────────────────────────┘
```

- 阶段行：`图标 阶段名 …… 耗时`，图标态 `○待/▶跑/✓完/—跳/✗错`；
- 气泡 = 状态一句话（替代旧版 detail+log 两行；日志尾行移入悬停 tooltip）。

### 3.2 收起态（168×~150 宠物条）

- 只留标题栏（头像+租户徽章，名称隐藏）+ 迷你气泡（如「跑链中 4/8」）；
- 点击宠物或头像恢复展开（旧版「—」收起按钮保留在展开态）。

### 3.3 悬浮预览（hover/长按宠物）

- 半透明最近一场战绩卡（拟新增，优先级低）。

## 4. 状态机与素材

| 状态 | 立绘 | 气泡文案 | 特效 |
| --- | --- | --- | --- |
| idle 待机 | Q版抱抱枕（眨眼帧） | 「待命中～把录像地址给我呀」 | 呼吸浮动 1.6px/2.8s |
| run 跑链 | Q版（同上，耳麦可加音符） | 「OCR 检测中…已识别 12 个击倒 ✨」（细目行滚动） | 浮动 5px/0.9s + 右上转圈 4/8 + 抱枕播放键呼吸发光 |
| done 完成 | face_c 点赞元气 | 「这场收获不错！击倒14 拾取9 语音6」 | 金黄星星粒子 ✦ + 阶段全绿 |
| err 出错 | face_b 吐舌俏皮 | 「呜…第4步 OCR 出错了，看看日志？」 | 阶段行标红 ✗ + 按钮变「重试」 |
| stop 停止 | face_b + zzz | 「手动停止了，素材我先收好…」 | 灰阶化 |

- 素材：`docs/pet-design/assets/`（随本设计交付）
  - `q_idle.png`：Q 版坐姿（原图 1065-1510, 535-1005 区域）——待机/跑链/收起态立绘；
  - `face_a.png / face_b.png / face_c.png`：三个半身表情差分
    （face_a=微笑常态，face_b=吐舌俏皮，face_c=点赞元气）——
    头像与跑链态用 face_a，完成态用 face_c（点赞），出错/停止态用 face_b；
  - 眨眼帧、zzz 帧：落码阶段用 PIL 从上述素材派生（闭眼帧=眼部区域向下模糊两行像素）；
  - tkinter 使用时需先转**透明背景 PNG**（原素材为米白底，抠图容差取 #F2EDE4 邻域）。

## 5. 交互流程

1. **开跑**：填/选录像地址 →（可选改租户）→ ▶ 开始 → 按钮变 ■ 停止，阶段逐个点亮；
2. **跑链中**：气泡滚动显示 parser 细目行；点击宠物可静音气泡（防止打扰）；
3. **完成**：星星特效 + 战绩条刷新为该场数据；主按钮回「▶ 开始跑链」；
4. **出错**：气泡给错误摘要（error_line），主按钮变「重试」（重跑同一地址）；
5. **改租户**：设置区输入 → 💾 → 回写 config.yaml `server.tenant` + 徽章刷新 + toast「已保存」；
   运行中禁改（推评估包阶段要用）；
6. **退出**：✕ 运行中先确认（保留旧逻辑）。

## 6. tkinter 落地方案（下一阶段）

| 设计元素 | tkinter 实现 | 备注 |
| --- | --- | --- |
| 圆角窗口 | `overrideredirect` + `-transparentcolor`（四角像素色） | Win10/11 可用；失败降级直角 |
| 立绘浮动/发光 | Canvas + `after(33ms)` 改 coords（复用现有 `_animate`） | — |
| 眨眼 | 双帧 PNG 定时切换（3s 眨 150ms） | PIL 派生闭眼帧 |
| 珊瑚粉渐变按钮 | Canvas 画渐变圆角矩形 + 文字 | 不用 ttk 按钮 |
| 阶段时间线 | 8 个 Frame 行 + 状态色 Label | 现有 stage_labels 改造 |
| 进度环（收起态） | Canvas `create_arc` | — |
| 星星粒子 | Canvas 随机坐标 create_text ✦，2s 淡出 | — |
| 字体 | `("Microsoft YaHei UI", size)` | 现有 FONT 复用 |

**降级链**：素材缺失/加载失败 → 回退现有 emoji 方案（保证任何环境可跑）。

## 7. 数据与配置

- 租户 ID：读 `toolbox.config`（config.yaml `server.tenant`）；写回用 yaml 安全 round-trip；
- 录像地址历史：沿用 `data/pet/history.json`（新增字段 `tenant` 快照，用于 UI 徽章显示）;
- 三线统计：沿用 `latest_stats()`。
